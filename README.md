# Jumanji-When-The-Drums-Begin
An immersive Jumanji-inspired interactive website featuring avatars, legends, creatures, villains, cinematic visuals, animations, and interactive game-card effects.

## 🌿 Project Overview

**Jumanji — When The Drums Begin** is an interactive front-end web experience inspired by the adventurous and mysterious world of Jumanji.

The project transforms the idea of a jungle adventure game into a multi-page website where users can explore different elements of the game world. Instead of presenting information through a traditional website layout, the project uses cinematic backgrounds, glowing symbols, themed typography, interactive cards, animations, and game-inspired visual elements to make the experience feel like entering the game itself.

---

## 🎯 Objectives

The main objectives of this project are:

- To design an immersive and visually engaging front-end website.
- To explore how storytelling can be incorporated into web design.
- To practice structuring a multi-page website using HTML5.
- To develop familiarity with utility-first styling using Tailwind CSS.
- To integrate ready-made UI components using Bootstrap and daisyUI.
- To implement interactive elements using JavaScript.
- To experiment with animations, hover effects, popovers, and interactive cards.
- To understand how images, icons, backgrounds, and typography can work together to create a consistent visual identity.

---

## 🧩 Methodology Used

The website was developed using a **design → structure → style → interaction → refinement** approach.

### 1. Concept & Visual Planning

The Jumanji theme was first translated into a visual direction based on:

- Jungle environments
- Ancient ruins and temples
- Golden game elements
- Adventure-inspired typography
- Character and creature artwork
- Dark cinematic backgrounds

The goal was to make each page feel like a different part of the same game world.

### 2. Page Structure

The website was divided into multiple sections:

- **Home** — introduction and entry point into the game
- **The Legends** — exploration of legendary characters
- **The Avatars** — interactive playable-character profiles
- **The Creatures** — dangerous creatures of the Jumanji world
- **The Villain** — introduction to the main antagonist
- **About** — information about the project

HTML5 semantic elements such as `<header>`, `<nav>`, `<main>`, `<section>`, and `<footer>` were used to organize the pages.

### 3. Visual Design & Styling

Tailwind CSS was used to control the visual appearance of the website.

The design was built using:

- Custom spacing and positioning
- Typography and letter spacing
- Background images
- Hover transformations
- Transitions
- Responsive utility classes
- Custom cursors
- Themed borders and colors

The **Cinzel** font was selected to complement the ancient and adventure-oriented theme.

### 4. Interactive Components

Interactive behavior was added using a combination of Bootstrap and JavaScript.

Bootstrap **Popovers** were used for the avatar symbols. When a user clicks an avatar, the corresponding character card appears as a popup instead of navigating to another page.

The cards were enhanced with daisyUI's **Hover 3D** component, allowing the card to respond visually to the user's mouse movement.

### 5. Animation & User Experience

Animations and transitions were added to make interactions feel smoother.

Examples include:

- Avatar icon hover scaling
- Navigation hover effects
- Logo animations
- Interactive 3D character cards
- Popup-based character information
- Custom cursor interactions

The intention was to keep the interface visually rich while maintaining a simple interaction pattern for the user.
